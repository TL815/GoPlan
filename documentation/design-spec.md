# GoPlan UI/UX 设计规范

> 基于 Dribbble 设计参考 `explore-design.png` 及现有设计资产提取，版本 v1.0

## 1. 设计理念

### 1.1 核心关键词

**温暖 · 轻盈 · 探索感 · 卡片叙事**

GoPlan 的设计语言追求现代极简与旅行情感的融合。不追求冰冷的高科技感，而是通过柔和的圆角、半透明层叠、克制的阴影和呼吸感的留白，营造"即将出发"的期待感。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 少即是多 | 每个页面聚焦一个核心动作，不堆砌信息 |
| 卡片叙事 | 以卡片为信息单元，营造翻阅明信片的自然感受 |
| 空间纵深感 | 通过层叠、毛玻璃、微阴影制造前后景深 |
| 触感反馈 | 所有可交互元素需有清晰的视觉状态变化 |
| 克制用色 | 中性色做骨架，品牌色做锚点，功能色做分类 |

## 3. 字体排版

### 3.1 字体族

| 平台 | 字体 | 回退 |
|------|------|------|
| iOS | SF Pro Text | System |
| Android | Roboto | System |

### 3.2 字号阶梯

| Token | 字号 | 行高 | 字重 | 用途 |
|-------|------|------|------|------|
| `text-xs` | 10px | 14px | 700 | POI标签、状态徽标 |
| `text-sm` | 11px | 15px | 400/700 | 日期、地址、筛选器 |
| `text-base` | 13px | 18px | 400/800 | 温度、地图摘要 |
| `text-md` | 14px | 20px | 400 | 占位文字、搜索框 |
| `text-lg` | 15px | 21px | 800/900 | 用户名、计划标题 |
| `text-xl` | 16px | 22px | 900 | 标题 |
| `text-2xl` | 18px | 24px | 700 | 按钮文案 |
| `text-3xl` | 22px | 28px | 900 | Logo标识 |

### 3.3 排版规则

- 标题与正文之间的间距为标题字号的 0.5 倍
- 英文与数字使用系统等宽变体，确保表格对齐
- 段落间使用空行分隔，不使用首行缩进
- 金额、时间等数字信息加粗处理

## 7. 核心组件规范

### 7.1 底部导航栏（BottomDock）

```
┌──────────────────────────────────────────────┐
│  ████████████████████████████████████████    │
│  ███  🏠    🗺️    📅    👤  ███    │  ← 22px bottom
│  ████████████████████████████████████████    │
└──────────────────────────────────────────────┘
   ← 258px →  高度58px  背景#050505  radius:29
```

- 宽度 258px，水平居中
- 高度 58px，底部距离 22px
- 背景色 `#050505`，圆角 29px
- 4个等距图标按钮，间距均匀分布
- 选中态：`#3C3C3C` 背景 + 白色图标
- 未选中态：透明背景 + `#726E6E` 图标

### 7.2 计划卡片（PlanCard）

- 最小高度 122px，宽度撑满父容器
- 背景白色，圆角 10px，`shadow-card` 阴影
- 左侧内容区：标题(15px w900) → 状态Chip → 日期(11px) → 指标行(icon+数字)
- 右侧路线预览：122×97px CustomPaint 手绘地图
- 计划卡片之间间距 12px

### 7.3 启动页海报卡片

- 三张卡片错落旋转层叠：
  - 卡片一：旋转 0.18 弧度，左偏移 29%，上偏移 10%
  - 卡片二：旋转 -0.34 弧度，左偏移 5%，上偏移 32%
  - 卡片三：旋转 0.36 弧度，左偏移 36%，上偏移 52%
- 圆角 20px，`ClipRRect` 裁剪
- 顶部渐变遮罩：`白色 → 0.6透明度白 → 透明`，停止点 `0 / 0.28 / 0.52`

### 7.4 底部主按钮

```
┌──────────────────────────────────────────┐
│  ┌────┐                                  │
│  │ Go │    去出发！                  →    │
│  └────┘                                  │
└──────────────────────────────────────────┘
```

- 背景 `#1C1C1E`，圆角 30px，高度 58px
- 左侧 "Go" 白色 Pill 标签：66×44px，圆角 24px
- 中间文字 "去出发！"：18px w700 白色
- 右侧箭头图标

### 7.5 AI 对话入口

- 高度 44px，圆角 24px，白色背景
- 内含 AI 魔法图标 + 占位文字 "来构筑你的想法......" + 麦克风图标
- `shadow-lg` 阴影

### 7.6 分类 Chip

- 高度 30px，圆角 15px
- 选中态：`#1C1C1E` 背景 + 白色文字 + 白色图标
- 未选中态：白色背景 + `#777777` 文字 + 彩色图标
- 内边距水平 12px
- 图标 15×15px，与文字间距 5px

### 7.7 POI 地图标记

- 外层白色圆形 22×22px，`shadow-md`
- 内层分类色圆形 12×12px
- 下方标签：半透明白色底，maxWidth 74px，8px 圆角
- 标签文字：10px w700 `#2F363A`

### 7.8 路线图绘制（CustomPainter）

绘制顺序（从底到顶）：
1. 背景底色 `#F5F7F5`
2. 水域贝塞尔曲线 `#DCEFF7`
3. 公园圆角矩形 `#E2F1E6`
4. 次干道平行线 `#E1E6E8`
5. 主干道白色路面 + `#D1D8DC` 阴影
6. 行程路线：白色底 5px + accent色 3.4px
7. 站点标记：起点绿色 / 终点accent色 / 中间白底+accent环
8. 文字标签：半透明白底圆角气泡

## 9. 交互动效规范

### 9.1 动画时长

| 类型 | 时长 | 曲线 |
|------|------|------|
| 页面切换 | 300ms | easeInOut |
| 按钮点击反馈 | 100ms | easeOut |
| 卡片出现 | 400ms | easeOutCubic |
| 列表滚动 | 跟随手势 | - |
| 启动动画 | 1500ms | custom |

### 9.2 启动页动画时序

```
0ms     → 背景图 + 渐变遮罩显示
200ms   → Logo 淡入（opacity 0→1, 400ms）
600ms   → 卡片三出现（translateY + rotation, 500ms）
800ms   → 卡片二出现（同上, 500ms）
1000ms  → 卡片一出现（同上, 500ms）
1500ms  → 按钮淡入 + 上滑（opacity + translateY, 400ms）
```

### 9.3 微交互

- 所有按钮按下时 scale 至 0.96，释放回弹至 1.0
- Chip 选中切换时有背景色过渡动画（200ms）
- POI 标记出现时带 scale 弹性动画（0→1.2→1.0）
- 卡片点击进入详情时有轻微 elevation 提升

- 所有网络图片需设置占位图和错误图

## 12. 适配规范

### 12.1 屏幕适配策略

- 基准设计稿宽度：375pt（iPhone 6/7/8）
- 使用 Flutter 的 `MediaQuery` + 弹性布局自适应
- 文字使用 `sp` 单位（自动跟随系统字体缩放）
- 卡片宽度使用百分比或 `Expanded`/`Flexible`
- 横屏模式：地图全屏 + 信息面板侧边栏

### 12.2 安全区

- 顶部：通过 `SafeArea` 处理刘海屏/挖孔屏
- 底部：Dock 组件距底 22px，为 iOS Home Indicator 预留空间
- Android 底部导航栏通过系统处理

---

## 13. 无障碍设计

- 所有交互元素最小触控区域 44×44pt（iOS HIG）或 48×48dp（Material Design）
- 关键信息对比度 ≥ 4.5:1（WCAG AA）
- 图片需提供语义化描述（`semanticLabel`）
- 支持系统字体缩放（最大 1.5x）
- v1.1+ 支持 VoiceOver/TalkBack 完整适配
