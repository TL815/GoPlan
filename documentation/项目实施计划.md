## 一、项目概述

### 1.1 项目名称

GoPlan AI旅行攻略规划应用

### 1.2 项目背景

GoPlan 是一款面向自由行用户的 AI 智能旅游攻略规划应用。用户通过自然语言对话或粘贴攻略链接，系统自动生成含景点、住宿、美食、交通的完整行程，并在地图上可视化展示路线。项目当前处于 v0.1 原型阶段，已完成 Flutter 跨平台 UI 原型和 Android/iOS 原生地图桥接骨架。

### 1.3 项目目标

| 维度 | 目标 |
|------|------|
| 功能目标 | 实现 AI 对话生成行程、攻略链接解析、地图路线可视化、行程编辑管理、行程分享等核心功能 |
| 质量目标 | 崩溃率 < 0.5%，首屏加载 ≤ 1.5s，AI 生成成功率 ≥ 90% |
| 时间目标 | 12周内完成 v1.0 MVP 开发并上架应用商店 |
| 成本目标 | 研发人力 5-6人，基础设施成本控制在预算范围内 |

### 1.4 项目范围

**包含：**
- Flutter 客户端（Android + iOS 双端）
- 后端 API 服务（Go 语言）
- AI 行程生成与攻略解析能力
- 高德地图 SDK 完整集成
- 用户系统（手机号注册/登录）
- 行程数据云端存储与多人协作
- 应用商店上架

**不包含：**
- 酒店/机票/门票预订接入
- 支付系统
- 内容社区/UGC 模块
- 国际化（非中文版本）

| R04 | 应用商店审核不通过 | 外部 | 低 | 高 | 中 | 提前研究审核指南 + 预留2周审核Buffer |
| R05 | Flutter 开发人员不足 | 资源 | 中 | 高 | 高 | 提前招聘确认 + 启用跨平台优势降低人力需求 |

| R07 | 多人协作冲突处理复杂 | 技术 | 中 | 中 | 中 | 乐观锁机制 + 简化v1.0协作范围 |
